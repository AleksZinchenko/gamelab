# gamelab — Лабораторія Ігор

Пісочниця для експериментів з розробкою та дизайном ігор для ПК і мобільних.
Прототипи механік, візуальний стиль, геймдизайн — швидко, маленькими кроками.

## Структура
- `experiments/` — експерименти, один = одна папка (`01-…`, `02-…`)
- `docs/` — нотатки з геймдизайну і словник термінів
- `ROADMAP.md` — план, `SESSIONS.md` — журнал сесій, `MEMORY.md` — факти, рішення і граблі

## Статус
Рушій ще не обрано — див. `ROADMAP.md`.
