# 01 — «Перед інспекцією» (робоча назва)

**Ідея.** Коротка (20–30 хв) point-and-click пригода в дусі Amanita Design: одна лабораторія, ніч перед
перевіркою з охорони праці, троє божевільних вчених, молодша інженерка і щуриця, що вкрала Дозвіл.
Без слів, без програшу, кілька шляхів, фінал з варіаціями. Натхнення — дух книги Вадима Артамонова
«Хроники лаборатории» (сюжет і жарти власні).

**Що пробували.**
- Сценарій v1 → дві рецензії субагентів (геймдизайн-плейтест, гумор/персонажі) → v2.
- Ілюстрація через Meshy (`gpt-image-2`, image-to-image з 4 вирізками з концепт-дошок) — 12 кредитів, з першої спроби.

**Файли.**
- `docs/scenario.md` — сценарій, ланцюжок задач, таблиця предметів (перевірка на тупики), журнал змін.
- `docs/characters.md` — характери, пластика, арки.
- `docs/scenario-graph.md` + `.png` — схема всіх варіацій (Mermaid).
- `docs/keyart_v1.jpg` — ілюстрація до сценарію.
- `docs/boards/` — концепт-дошки: `board1_pitch.png` (герої, тепла палітра), `board2_lab.png` (основа локації).

**Що далі.** Відповіді на відкриті питання (назва, імена, «без слів») → вертикальний зріз
(Пролог + Акт I) через `/ref2game`.
