# 01 — «Перед інспекцією» (робоча назва)

**Ідея.** Коротка (20–30 хв) point-and-click пригода в дусі Amanita Design: одна лабораторія, ніч перед
перевіркою з охорони праці, троє божевільних вчених, молодша інженерка Ліна і щуриця, що вкрала Дозвіл.
Без слів (думки — намальовані бульбашки), без програшу, кілька шляхів, фінал з варіаціями. Натхнення — дух книги
Вадима Артамонова «Хроники лаборатории» (сюжет і жарти власні).

## Стан на 2026-10-19 — вертикальний зріз «Пролог + Акт I» (у роботі)
Грається в браузері (ПК і телефон, горизонтально), від прологу до «світло є → факс друкує УСТАНОВКА».

**Готово**
- Сценарій v2.1 (`docs/scenario.md`), персонажі (`docs/characters.md`), схема варіацій (`docs/scenario-graph.*`),
  розкадровка кінематографічного прологу (план, `docs/scenario.md` → «Пролог v2»).
- Стиль: **гуаш** (`art/style_bible.txt`, еталон `ref.png` = `docs/keyart_v3_gouache.png`). Гаму Machinarium пробували — лишили теплу нічну.
- Фон кімнати — панорама 3588×1080 з двох половин, шов схований у вертикальній трубі (`tools/stitch.py`).
- Логіка (`live/sim.js` + дані `live/story.js`): ходьба по тапу, рюкзак, перетягування речей на предмети,
  темрява з плямами світла, обидва шляхи до світла (I-A ключ з акваріума → Двічі; I-B три ковтки Мирона → Мирон-ліхтар),
  смішні помилки, навчання без слів (палець), мерехтіння активних речей, нотатник-підказка зі стрілкою, демо, що грає саме.
  Самоперевірка: обидва шляхи вмикають світло (`node live/tune.cjs` → `selfCheck ok`).
- Пролог 22 с зі стоп-кадрами-картками «хто є хто» (тап — пропустити).
- Інтерфейс: бульбашки — намальовані рамки + 24 олівцеві піктограми (замість емодзі); рюкзак, нотатник, предмети — гуаш.
- **Ліна — маріонетка**: ноги з аркуша частин (ліва/права окремо, хода з IK, ступні не ковзають); верх — якір,
  руки згинаються «м'якими кістками» поверх тіла, яке Meshy перемалював без рук (`live/puppet.js`). QA ходи пройдено.
- Академік (спить, дихає), щуриця (біжить кабелем), Аксель (плаває) — намальовані спрайти з деформаціями.
- **Двічі й Мирон — маріонетки** (2026-10-19): ноги з аркушів частин (`tools/rig_lr.py`), верх — якір: тіло з Meshy-версії
  «без рук», дальня рука на м'яких кістках, ближня — два жорсткі шматки (плече + передпліччя з круглими суглобами,
  `tools/make_top.py`), бо великі жести на м'яких кістках тягнуться «локшиною». Двічі: ноги з-під машини (коліна смикаються)
  → вилазить → іде → два удари ключем. Мирон: пробірка в руці, ковток до рота (після кожного ковтка Ліни й сам раз на ~7 с),
  іде до крісла й котиться на ньому стоячи, як на самокаті (сидячи довгий нерухомий плащ не читався); очі світяться
  в темряві, борода — фіолетовим. Крісло поки greybox.

**Далі (по порядку)**
1. Крісло на коліщатках — намальоване (зараз greybox); Двічі вилазить з-під машини «стрибком» — додати проміжну позу.
2. Ліна: стояча «жива» поза (дихання), жести (тягнеться до акваріума, стрибок у пролозі), обличчя.
3. Палець-підказка — намальований (зараз емодзі 👆), звук (`live/audio.js` — заглушка).
4. Пролог v2 — кінематографічна катсцена (камера з масштабом, плани, наїзди) — після всіх героїв.
5. Критики (асети, кадр, рух, відчуття гри) і доводка; `pack.py` — статична збірка.

## Як запустити
```
cd experiments/01-before-inspection
bash ../../.claude/skills/ref2game/scripts/serve.sh        # у фоні → http://127.0.0.1:8930/live/index.html
node live/tune.cjs                                         # демо доходить до світла + selfCheck обох шляхів
node ../../.claude/skills/ref2game/scripts/qa.mjs          # перевірки інтерфейсу й ходи Ліни
```
Телефон: тунель localhost.run (див. `MEMORY.md` → «Граблі»).

**Конвеєр графіки** (після кожної нової картинки): `art/gen/*.png` → `python ../../.claude/skills/ref2game/scripts/prep.py`
→ `python tools/web.py` (JPEG для фону, палітра для UI — інакше телефон через тунель качає хвилинами).

## Файли
- `docs/` — сценарій, персонажі, схема, ілюстрації, концепт-дошки (`docs/boards/`).
- `art/style_bible.txt` — біблія стилю (йде в кожен запит до Meshy); `art/prompts/` — усі запити.
- `art/gen/` — затверджені картинки (джерело правди); `art/src/` — аркуші, половини фону, редагування (джерела нарізки).
- `live/` — гра: `story.js` (дані), `sim.js` (логіка), `scene.js` (малювання), `puppet.js` (маріонетки), `rigs.js` (суглоби),
  `sizes.js` (розміри на екрані), `assets/` (текстури після prep + web).
- `tools/` — `stitch.py` (панорама), `ui_sprites.py` (нарізка піктограм), `web.py` (стиснення), `gen_raw.py` (генерація без
  біблії стилю), `rig_lr.py` (маріонетка з лівих/правих кінцівок), `split_arms.py` (шар рук окремо від тіла), `make_top.py` (верх
  маріонетки: тіло «без рук» + м'яка дальня рука + жорсткі шматки ближньої), `grid.py` (сітка координат на картинці),
  `snap.mjs` (кадр із заданого стану гри — пози, до яких демо не доходить).
- `study/` — референси, проби стилю, промпти еталонів.
