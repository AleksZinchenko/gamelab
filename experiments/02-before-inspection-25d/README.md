# 02 — «Перед інспекцією» у 2.5D

## Ідея
Та сама гра, що в `01-before-inspection`, але:
- **персонажі — 3D-моделі з Meshy** (картинка → модель → автоскелет → рухи з бібліотеки) замість 2D-маріонеток з нарізаних рук і ніг;
- **камера віддалена (масштаб 0.35)**: персонаж ~140 px заввишки з 1080, як в Amanita (Samorost, Machinarium);
- **будинок у розрізі**: на екрані кілька кімнат одночасно, наша лабораторія — один із поверхів;
- фони лишаються мальованими (гуаш), рендер — **three.js** (замість 2D-мінірушія ref2game).

Чому так — проби 2026-10-29 в `01-before-inspection` (`tools/zoom_mock.py`, `tools/meshy3d.py`, `tools/render3d.mjs`):
хода 3D-моделі природна одразу, а на дрібному масштабі різниця «3D з Meshy ↔ гуаш» майже не видна.
Стиль 3D — «як є», без стилізації: мультяшне світло й «мазки» на 140 px не відрізнити.

## Як запустити
```
node tools/shot.mjs serve            # сервер на http://127.0.0.1:8931
node tools/shot.mjs shot frames/a.png 4     # знімок демо (?auto=1) через 4 с
node tools/shot.mjs video frames/demo.mp4 16
```
Тап/клік по підлозі лабораторії — Ліна йде туди (і вглиб кімнати); по стіні — лише вздовж.

## Будова
- `src/main.js` — рендерер, ортографічна камера «будинок у розрізі», світло для 3D-героїв, дотики, ігровий цикл.
- `src/building.js` — план будинку: кімнати (обриси під дахом і куполом), зріз стін і перекриттів з прорізами, дах, вежа.
- `src/decor.js` — живий фон: вогники ламп (рівні / мерехтливі / «таємничі»), світло з прочинених дверей, двері, ляда, ліфт.
- `src/actor.js` — 3D-герой: модель, хода/дихання з плавним переходом, жести «один раз», поворот у ракурсі 3/4, тінь, глибина підлоги.
- `src/cast.js` — колеги в лабі (Двічі, Мирон, Академік): де стоять, які рухи, що роблять самі.
- `vendor/` — three.js r170 (своя копія, без інтернету). `assets/` — фон лаби і `lina.glb`.
- `tools/glb_shrink.py` — готує GLB з Meshy: текстура 1024 JPEG, без карти нормалей і тангентів, усі рухи в один файл
  (13.7 МБ → 3.2 МБ). gltf-transform на Windows не працює (падає libvips) — тому свій скрипт.

## Ліна: рухи і світло
- Стійки «рівненько, як вихована дівчинка» — Idle_4 / Idle_3 / Idle_12 з бібліотеки Meshy, чергуються самі
  (стара Idle 0 стояла «піратом»: ноги й руки розставлені). Хода — Thoughtful_Walk (дрібні кроки) у темпі ×1.35;
  голову й шию хода не рухає (`walkSkip`) — інакше Ліна дивиться під ноги.
- Швидкість ходи гра міряє з самої анімації (`strideSpeed` в `actor.js`): ступня на підлозі не ковзає за будь-якої ходи.
- Світло: тінь під підборіддям виглядала як борода → розсіяне знизу тепле (відбиття від підлоги), головна лампа нижче,
  м'яке заповнююче спереду. `?zoom=1.6` — наблизити камеру до героїні для перевірки.

## Кредити Meshy
- Проба 3D-Ліни (в 01): 43 кр — модель 30, спрощення сітки 5 (942 тис. трикутників → 40 тис., скелет приймає ≤320 тис.),
  скелет 5 (хода й біг у комплекті), дихання 3.
- 2026-10-29: 5 рухів для Ліни (3 стійки + 2 ходи) — 15 кр; кабінет Шефа — 12 кр; ще 7 кімнат (сходи, архів, бухгалтерія,
  сусідня лаба, хол, майстерня, котельня) — 84 кр, усі з першої спроби; перебудова будинку — 10 картинок, 120 кр
  (вежа, горище, високий архів, бухгалтерія і сусідня лаба в нових кольорах, підвал, шахта, текстура зрізу, аркуш
  деталей, сходи з маршем в отвір у стелі — перша версія сходів упиралась у бічну стіну).
- Крок 3 (колеги в 3D): 174 кр — Академік стоячи 12 (в 01 він сплячий, зі скрюченої пози скелет не зробиш),
  3 моделі 90, спрощення 15, скелети 15, 14 рухів 42. Баланс після — 712.
  Рухи: Двічі — Casual_Walk, Idle_02, Idle_7, Heavy_Hammer_Swing; Мирон — Thoughtful_Walk, Idle_9, Idle_7,
  Stand_and_Drink, Scheming_Hand_Rub; Академік — Elderly_Shaky_Walk, Confused_Scratch, Idle_9, Sleep_on_Desk, Cheer.
