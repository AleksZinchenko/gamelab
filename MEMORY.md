## Граблі (на які вже наступали — не повторювати)
- PowerShell `@'…'@` у Bash-інструменті ламає повідомлення коміта (див. CLAUDE.md, розділ «Коміти»).
- `python3` у Windows — заглушка Microsoft Store, а не Python. Скрипти викликати через `python`.
- Консоль Windows у cp1251: Python падає з `UnicodeEncodeError` на символах типу `→`. Ліки — `PYTHONUTF8=1`
  (прописано в `.claude/settings.json`; у вже запущеній сесії — `export PYTHONUTF8=1` перед командою).
- Node ESM: `new URL(import.meta.url).pathname` на Windows дає `/C:/...` → «MODULE_NOT_FOUND». Тільки `fileURLToPath`.
- Скіли/скрипти «для macOS і Linux» (ref2game) перед використанням проганяти на тестовому проєкті в scratchpad.
- Встановлення з правами адміністратора (winget/MSI) при віддаленій роботі з телефону зависає на вікні UAC,
  яке нікому натиснути. Ставити портативні версії в `C:\Soft\` (так поставлено `C:\Soft\cloudflared\cloudflared.exe`).
- `trycloudflare.com` (швидкі тунелі cloudflared) з цієї мережі недоступний — таймаут, хоча cloudflare.com відкривається.
  Вхідні тунелі (localhost.run тощо) Claude Code у режимі auto блокує — лише з явного дозволу користувача.
  Користувач дозволив localhost.run (2026-10-15), перевірено — працює: `ssh -o StrictHostKeyChecking=accept-new
  -R 80:127.0.0.1:<порт> nokey@localhost.run` (у фоні, URL `https://<id>.lhr.life` — з логу). Адреса щоразу нова
  і без акаунта змінюється сама вже за лічені хвилини (стара видає «no tunnel») — перед тим як давати
  посилання, брати найсвіжішу `*.lhr.life` з кінця логу. Довша адреса — акаунт localhost.run + SSH-ключ.
  Після сесії тунель вимикати: зупинка фонової задачі НЕ вбиває `ssh.exe` — добивати `taskkill //PID <pid> //F`
  (перевірити `tasklist //FI "IMAGENAME eq ssh.exe"`). Вузли Cloudflare :7844 доступні —
  іменований тунель cloudflared запрацює, якщо з'явиться свій домен на Cloudflare.
